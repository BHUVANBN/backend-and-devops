cors - cross origin resource sharing 
- when frontend and backend run on different ports, cors is used to allow them to communicate
ways to add cors:
1. using package - npm i cors
    eg: import cors from 'cors'
        app.use(cors())
        
2. proxy in vite (for frontend)
   eg: in vite.config.js
   export default defineConfig({    
    server:{
        proxy: {
            "/api" : "http://localhost:3000"
        }
    }
   })

data modeling - creating schemas, collections and documents, in models folder
// Database - mongoDB, Object Document Mapper - mongoose
//or Database - PostgreSQL, Object Relational Mapper - prisma
// Creating schemas in mongoose: 

import mongoose from "mongoose";
const userSchema = new mongoose.Schema({ //schema - structure of the document
    name: {
        type: String,
        required: true,
        trim: true,
        minLength: 3,
        maxLength: 30
    },
    email: {
        type: String,
        required: true,
        unique: true,
        lowercase: true,
        trim: true,
        validate: {
            validator: function(v) {
                return /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(v);
            },
            message: "Please enter a valid email address"
        }
    },
    password: {
        type: String,
        required: true,
        minLength: 6
    }, 
}, {timestamps: true});
export const User = mongoose.model("User", userSchema); //model - class for creating documents

dev dependencies vs production dependencies: 
dev dependencies - libraries used during development eg: nodemon, dotenv, cors, etc 
production dependencies - libraries needed for the application to run eg: express, mongoose, etc 

to install dev dependencies: npm i -D <package_name>
eg: prettier - to format code, prettierrc file for rules, .prettierignore file to ignore files to apply prettier
    nodemon - to watch and restart server    

production dependencies: npm i <package_name>
eg: express - web framework, mongoose - object data modeling, dotenv - to handle environment variables

configuring app via middlewares in app.js:
middleware - functions that run between request and response, can be used as app.use(middleware)

1. cors middleware - to allow backend to receive requests from specified frontend url
    eg: app.use(cors({ //middleware for cors
        origin: process.env.CORS_ORIGIN, //frontend url should be here to allow requests
        credentials: true //to allow cookies to be sent with requests
    }))

2. json middleware - express.json({limit:"16kb"}) //to allow backend to parse json data from requests
3. url encoded middleware - express.urlencoded({extended:true, limit:"16kb"}) //to allow backend to parse url encoded data from requests
4. static files middleware - express.static("public") //to serve static files from public folder
5. cookies middleware - npm i cookie-parser //to allow backend to access cookies from user browser and set them for crud operations on cookies
