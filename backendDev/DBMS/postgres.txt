Postgres - Object-Relational DBMS
SQL is a language to interact with DB

To use postgres we can access database via cli - psql(official) or pgcli

+--------------------+-----------------------------------------------+
| Meta Command       | Description                                   |
+--------------------+-----------------------------------------------+
| `\?`               | Show help for all meta-commands               |
| `\h`               | SQL command help                              |
| `\q`               | Quit psql                                     |
| `\c` or `\connect` | Connect to another database                   |
| `\conninfo`        | Display current connection info               |
| `\password username| Change a user's password                      |

| `\dn`              | List schemas                                  |
| `\dt`              | List tables                                   |
| `\dt+`             | List tables with additional information       |
| `\dv`              | List views                                    |
| `\dm`              | List materialized views                       |
| `\ds`              | List sequences                                |
| `\di`              | List indexes                                  |

| `\df`              | List functions                                |
| `\df+`             | Detailed function information                 |
| `\da`              | List aggregate functions                      |
| `\do`              | List operators                                |
| `\du`              | List roles/users                              |
| `\dg`              | List roles (same as `\du`)                    |
| `\db`              | List tablespaces                              |
| `\dx`              | List installed extensions                     |

| `\pset`            | Change output format                          |

CONSTRAINTS

PRIMARY KEY      Uniquely identifies each row in a table.
                 Automatically enforces NOT NULL and UNIQUE.
                 A table can have only one primary key.
                 Example: id INT PRIMARY KEY
FOREIGN KEY      Ensures values in one table match values
                 in another table.
                 Maintains relationship between tables.
                 Example: customer_id INT REFERENCES customers(id)
UNIQUE           Ensures all values in a column or group
                 of columns are different.
                 Allows NULL values.
                 Example: email VARCHAR(100) UNIQUE
NOT NULL         Prevents a column from storing NULL values.
                 The column must always have a value.
                 Example: name TEXT NOT NULL
CHECK            Ensures values satisfy a specified condition
                 before insertion or update.
                 Example: age INT CHECK(age >= 18)
DEFAULT          Assigns a default value to a column when
                 no value is provided during insertion.
                 Example: status TEXT DEFAULT 'active'
EXCLUSION        Prevents rows from conflicting based on
                 a specified operator condition.
                 Commonly used for ranges and scheduling.
                 Example:EXCLUDE USING gist
                 (room WITH =, booking_time WITH &&)
