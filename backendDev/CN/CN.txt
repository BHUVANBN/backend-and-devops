Protocols - rules defined to communicate on networks, defined by Internet Society.
Eg: TCP, UDP, IP, HTTP, HTTPS

IP Address is a address of a device on network layer

MAC address device physical address hardcoded on Network interface card to identify device
To know MAC address - networksetup -getmacaddress Wi-Fi

IP address tells the network layer where the destination is.
MAC address tells the Ethernet/data-link layer which device on the local network should receive the frame. Ethernet needs a MAC address to work.

Port - address for every applications in the device, 16 bit number so total ports available = 2^16 = 65,536
Reserved ports - 0 to 1023 - Used by standard services and protocols
Registered ports - 1024–49151 - Used by applications and services registered with IANA.
Private ports/Ephemeral ports - 49152–65535 - Usually used temporarily by client applications for outgoing connections.

NETWORK DEVICES AND THEIR OSI LAYERS
====================================

1. NIC (NETWORK INTERFACE CARD)
--------------------------------
- Connects a computer/device to a network.
- Can provide Ethernet or Wi-Fi connectivity.
- Operates mainly at the Physical Layer and Data Link Layer.
- Has a MAC address.
- Examples:
  - Ethernet network card
  - Wi-Fi adapter
- Receives bits and formatted into a frame 
[dest Mac | src Mac | dest IP | src IP | data | Frame Check Seq ]
CRC is calculated and if it is matched with CRC in the FCS in frame it checks the dest Mac with the NIC Mac and processes the data by creating packet with 
 | dest IP | src IP | data |
If CRC does not match it discards the frame
- does the reverse process when sending packets
OSI Layer: Layer 1 + Layer 2

2. MODEM
--------
- Modem = MOdulator + DEModulator.
- Converts digital data to signals suitable for transmission over
  certain communication media and converts received signals back.
- Traditionally, a modem converts digital data to analog signals
  for transmission over analog telephone lines and converts analog
  signals back to digital data.
- Modern cable/DSL/fiber "modems" may use more complex signaling
  rather than simply digital-to-analog conversion.
- Usually connects a home/network to an ISP.
OSI Layer: Depends on the modem technology; mainly Physical Layer,
with some Data Link-layer functions in modern broadband equipment.

3. REPEATER
-----------
- Operates at the Physical Layer.
- Regenerates or reshapes weakened signals.
- Extends the transmission distance of a network.
- Does not understand IP addresses or MAC addresses.
- Does not make routing decisions.
- A traditional repeater has two interfaces/ports.
OSI Layer: Layer 1 (Physical Layer)

4. HUB
------
- A hub is basically a multiport repeater.
- Operates at the Physical Layer.
- Receives a signal on one port and repeats it to all other ports (multiport repeater, used in star topology)
- Does not examine MAC addresses.
- Does not examine IP addresses.
- All devices connected to a traditional hub share the same
  collision domain.
- Hubs are largely obsolete and have been replaced by switches.
OSI Layer: Layer 1 (Physical Layer)

5. BRIDGE
---------
- Connects two LAN segments.
- Operates at the Data Link Layer.
- Uses MAC addresses to decide whether to forward or filter frames.
- Reduces unnecessary traffic between network segments.
- A bridge is essentially an early/simpler form of a switch.
OSI Layer: Layer 2 (Data Link Layer)

6. SWITCH
---------
- Connects multiple devices within a LAN.
- Mainly operates at the Data Link Layer.
- Uses a MAC address table to forward Ethernet frames.
- Sends a frame only toward the appropriate destination port
  when the destination MAC address is known.
- Each switch port is normally a separate collision domain.
- Modern switches can also perform Layer 3 functions.
OSI Layer: Mainly Layer 2
Some switches: Layer 3

7. ROUTER
---------
- Connects different networks.
- Operates mainly at the Network Layer.
- Uses IP addresses to make forwarding/routing decisions.
- Determines where packets should be forwarded.
- Separates broadcast domains.
- Connects networks such as:
  LAN -> Internet
  LAN -> LAN
  Private network -> Public network
OSI Layer: Layer 3 (Network Layer)

8. GATEWAY
----------
- A gateway connects networks or systems that may use different
  protocols, architectures, or communication methods.
- It can perform protocol translation between different systems.
- In everyday networking, "default gateway" usually refers to
  the router that forwards traffic from a local network to other
  networks.
- A gateway is not restricted to one OSI layer.
OSI Layer: Can operate at multiple layers,
depending on the type of gateway.

9. WIRELESS ACCESS POINT (AP)
-----------------------------
- Provides wireless network access to Wi-Fi devices.
- Connects wireless devices to a wired LAN.
- Primarily operates at the Data Link Layer.
- Uses MAC addresses for wireless frame communication.
- Converts/bridges wireless LAN traffic to the wired LAN.
OSI Layer: Mainly Layer 2
Physical Layer functions are also involved.

10. FIREWALL
-----------
- Controls and filters network traffic according to security rules.
- Can allow or block traffic based on:
  - IP addresses
  - Port numbers
  - Protocols
  - Connection state
  - Applications/content (depending on firewall type)
- Firewalls can operate at multiple OSI layers.
- A basic packet-filtering firewall can work mainly at Layers 3 and 4.
- Modern firewalls can operate at higher layers as well.
OSI Layer: Layer 3, Layer 4, and sometimes higher layers

11. PROXY SERVER
---------------
- Acts as an intermediary between a client and another server.
- The client sends a request to the proxy.
- The proxy forwards the request to the destination server.
- Can provide:
  - Caching
  - Access control
  - Privacy
  - Content filtering
  - Traffic monitoring
- A proxy can operate at different layers depending on its type.
OSI Layer: Usually Layer 7 for application proxies

12. LOAD BALANCER
-----------------
- Distributes incoming network/application traffic across
  multiple servers.
- Helps improve:
  - Performance
  - Availability
  - Scalability
  - Fault tolerance
- Can make decisions using IP addresses, ports, TCP connections,
  HTTP requests, URLs, etc.
- Layer 4 load balancer -> TCP/UDP connections
- Layer 7 load balancer -> Application-level information
OSI Layer: Layer 4 or Layer 7

13. MULTIPLEXER (MUX)
---------------------
- Combines multiple signals/data streams into one communication
  channel.
- Allows multiple signals to share the same transmission medium.
- A demultiplexer (DEMUX) separates the combined signals at
  the receiving end.
OSI Layer: Depends on implementation

14. CS (CIRCUIT SWITCH)
----------------------
- Establishes a dedicated communication path between two endpoints.
- The path remains reserved for the duration of the communication.
- Traditional telephone networks used circuit switching.
- Modern Internet communication mainly uses packet switching.
OSI Layer: Not tied to a single OSI layer

15. IDS (INTRUSION DETECTION SYSTEM)
------------------------------------
- Monitors network/system activity for suspicious or malicious
  behavior.
- Detects threats and generates alerts.
- Normally does not automatically block traffic.
OSI Layer: Can inspect multiple layers

16. IPS (INTRUSION PREVENTION SYSTEM)
-------------------------------------
- Detects suspicious or malicious traffic.
- Can automatically block or prevent detected threats.
- Usually placed inline with network traffic.
OSI Layer: Can inspect multiple layers

17. WAF (WEB APPLICATION FIREWALL)
----------------------------------
- Protects web applications from application-layer attacks.
- Examines HTTP/HTTPS traffic.
- Can block malicious requests such as certain types of:
  - SQL injection
  - Cross-site scripting (XSS)
  - Malicious HTTP requests
OSI Layer: Layer 7 (Application Layer)

18. DHCP SERVER
--------------
- Automatically provides network configuration to clients.
- Can provide:
  - IP address
  - Subnet mask
  - Default gateway
  - DNS server
- DHCP is an Application-layer protocol.
OSI Layer: Layer 7

19. DNS SERVER
-------------
- Converts domain names into IP addresses and can perform
  other DNS lookups.
- Example:
  www.example.com -> IP address
- DNS is an Application-layer service.
OSI Layer: Layer 7

20. SERVER
---------
- Provides services/resources to other devices (clients).
- Examples:
  - Web server
  - File server
  - Mail server
  - Database server
  - DNS server
  - DHCP server
OSI Layer: Depends on the service/application.

STRUCTURE OF THE NETWORK: OSI (OPEN SYSTEMS INTERCONNECTION) MODEL

7. APPLICATION LAYER
--------------------
- Provides network services to applications.
- Applications generate and consume data at this layer.
- Data formats/encodings may include ASCII, UTF-8, JSON, XML, etc.
- Examples: HTTP, HTTPS, FTP, DNS, SMTP, Telnet

6. PRESENTATION LAYER
---------------------
- Handles data translation/formatting.
- Performs encryption and decryption.
- Performs data compression and decompression.
- Character-code translation can be performed here (e.g., ASCII to EBCDIC).
- TLS/SSL is commonly associated with this layer in the OSI model.

5. SESSION LAYER
----------------
- Establishes, manages, and terminates communication sessions.
- Provides session synchronization and checkpoints.
- Helps manage ongoing communication between applications.

4. TRANSPORT LAYER
------------------
- Performs segmentation of application data.
- Uses source and destination port numbers.
- Provides sequencing and reliable delivery with TCP.
- Provides congestion, flow control and error recovery with TCP.
- Adds a checksum for error detection.
- TCP and UDP operate at this layer.
- TCP provides reliable, connection-oriented communication.
- UDP provides connectionless communication with lower overhead.
- FTP is NOT a Transport-layer protocol; FTP is an Application-layer protocol.
- TCP PDU = Segment
- UDP PDU = Datagram

3. NETWORK LAYER
----------------
- Provides logical addressing using IP addresses.
- Adds source and destination IP addresses.
- Encapsulates transport-layer data into IP packets.
- Performs routing and packet forwarding.
- Routers primarily operate at this layer.
- IPv4 and IPv6 operate at this layer.
- PDU = Packet
- A router routes packets between different IP networks. Each router interface separates broadcast domains and also separates Layer-2 collision domains
- router ports/interfaces - Gi0/0, Gi0/1 (Gigabit ithernet)
- connects switch
- layer 3 switch = layer 2 switch + route processor

Firewall: next-generation, stateful (allows the data only if asked from any website, and only from allowed websites)
Deep packet inspection, application awareness and control

IPS(Intrusion prevention system): Real-time monitoring, Signature-based detection, anomaly detection

2. DATA LINK LAYER
------------------
- Provides physical addressing using MAC addresses.
- Adds source and  destination MAC addresses.
- Encapsulates the Network-layer packet into a frame.
- Performs framing.
- Performs error detection.
- Handles access to the physical transmission medium.
- Ethernet and Wi-Fi have Data Link-layer functions.
- PDU = Frame
- layer 2 switch contains ports with the connected device MAC addresses, switches has collision domains (ports create collision domain, so each devices data is not collided) and 1 broadcast domain(sends data to all connected device)

Hub(old device) used to connect all devices which caused collision, it has single collision and broadcast domain

Bridges reduces collision by learning MAC address of the connected devices using software but it is very slow compared to the switch(done using ASIC hardware, and has more ports / collision domains)

Access point for wireless connection, controller is used to configure the light weight access points, so the switch is connected in between the controller and access point via PoE ethernet and configured using controller

1. PHYSICAL LAYER
-----------------
- Transmits raw bits (0s and 1s).
- Deals with physical hardware and transmission media.
- Fiber-optic cables transmit data using light signals.
- Copper cables transmit data using electrical signals.
- Wireless networks transmit data using radio signals.
- PDU = Bits

Transport Layer protocols:
TCP: Transmission Control Protocol
	divides the data into chunks and adds tcp header
TCP HEADER

  0                   15 16                  31
  +---------------------+---------------------+
  |     Source Port     |   Destination Port  |
  +---------------------+---------------------+
  |              Sequence Number              |
  +-------------------------------------------+
  |           Acknowledgment Number           |
  +----+------+---------+---------------------+
  |HLEN| Res. |  Flags  |     Window Size     |
  +----+------+---------+---------------------+
  |       Checksum      |   Urgent Pointer    |
  +---------------------+---------------------+
  |          Options (if present)             |
  +-------------------------------------------+
  |                  Data                     |
  +-------------------------------------------+

Source Port       → Sending application's port
Destination Port  → Receiving application's port
Sequence Number   → Position of data in the TCP byte stream
ACK Number        → Next byte expected from the other side
HLEN/Data Offset  → Size of TCP header
Flags             → SYN, ACK, FIN, RST, PSH, URG, etc.
Window Size       → Receiver's available buffer / flow control, how much data can be sent at a time
Checksum          → Detects errors
Urgent Pointer    → Points to urgent data when URG is set
Options           → MSS, Window Scale, SACK, Timestamps, etc.
Data              → Application data

	connection oriented - 3 way handshake to establish a reliable TCP connection between Client and Server before data transfer.
Client                              Server
  |                                   |
  | SYN, Seq=X                        |

IP TRAFFIC TYPES
1. UNICAST: One sender → One specific receiver
Example: 192.168.1.10 → 192.168.1.20
Used when data is intended for one specific device.

2. BROADCAST: One sender → All hosts in the local broadcast domain
Example: 192.168.1.10 → 192.168.1.255
Limited Broadcast: 255.255.255.255
255.255.255.255 means: Send to all hosts on the local network.
Routers normally do not forward IPv4 broadcasts.

3. MULTICAST: One sender → Specific group of receivers
IPv4 multicast range: 224.0.0.0 – 239.255.255.255
Example: 192.168.1.10 → 224.0.0.1
Only devices that have joined the multicast group receive the traffic.
Historically called Class D.

4. ANYCAST: One sender → One destination selected from multiple devices
Usually the nearest/best destination according to routing.
Example:
             ┌── Server A
             │
Client ──────┼── Server B
             │
             └── Server C

All servers advertise the same IP.
The network routing system selects the best/nearest server.
Commonly used by:
- DNS services
- CDNs
- Distributed services

SUMMARY
UNICAST: One → One
BROADCAST: One → All hosts in local broadcast domain
MULTICAST: One → Specific group
ANYCAST: One → One of many equivalent destinations

2001:0db8:85a3:0000:0000:8a2e:0370:7334
IPv6 TRIMMING RULES
1. Remove leading zeros from each block: 2001:0db8:85a3:0000:0000:8a2e:0370:7334 → 2001:db8:85a3:0:0:8a2e:370:7334
2. Replace consecutive zero blocks with :: 2001:db8:85a3:0:0:8a2e:370:7334 → 2001:db8:85a3::8a2e:370:7334
3. Use :: only once: 2001:db8:85a3::8a2e:370:7334 → Valid; 2001::db8::8a2e → Invalid
4. :: represents one or more complete 16-bit zero blocks: 2001:db8:85a3::8a2e:370:7334 → 2001:0db8:85a3:0000:0000:8a2e:0370:7334
5. Do not remove zeros from the middle of a block: 2001:0db8:85a3:0000:0000:8a2e:0370:7334 → 2001:db8:85a3:0:0:8a2e:370:7334
6. Compress the longest consecutive zero sequence: 2001:0db8:85a3:0000:0000:8a2e:0370:7334 → 2001:db8:85a3::8a2e:370:7334

Same subnet mask will apply in ipv6 2001:db8:85a3::1/64
