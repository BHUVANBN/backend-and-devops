chapter4 
prisma - orm (object relational mapper) - act as a layer between the application and the database
npm i prisma @prisma/client 
npx prisma init - initialize prisma in the project , creates a prisma folder with schema.prisma file which contains the database schema
npx prisma migrate dev --name add_users - feature of prisma to create tables in the database, it makes updates to the database schema
npx prisma generate - generates the prisma client code based on the schema.prisma file
